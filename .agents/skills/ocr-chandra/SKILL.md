# ocr-chandra

## 실행 환경
Cofa 응시에서는 docs/hackathon.md와 AGENTS.md의 대회 제한을 먼저 적용한다. 외부 API/추가 AI 모델은 실행하지 않는다. 다른 대회와 일반 연습은 해당 환경의 허용 범위를 확인한다.

## 입력·출력
입력: PDF/이미지, 중요한 필드, 모델 허용 범위. 출력: 원문 Markdown/JSON, 원본 페이지·영역 매핑, 불확실 필드.
## 절차
1. https://github.com/datalab-to/chandra 의 현재 README, 코드 LICENSE와 MODEL_LICENSE를 각각 확인한다. 코드 Apache-2.0과 모델 조건은 다르며 상업적 자체 호스팅 조건도 확인한다.
2. 사용 허용 환경에서 별도 가상환경에 `python -m pip install "chandra-ocr[hf]"`로 설치한다. 가중치·메모리/GPU 요구량을 확인하고 작은 공개/합성 자료부터 처리한다.
3. `chandra input.pdf output --method hf`로 로컬 추론한다. 기본 vLLM/호스팅 경로를 무심코 쓰지 않는다. 모델 다운로드와 실제 문서 전송을 구분한다.
4. 도구 버전·모델/가중치 식별자·설정·원본 SHA-256을 기록하고 페이지/영역별 결과를 원본에 연결한다.
5. 표 병합·수식·이름·숫자를 원본 대조한다. Tesseract 또는 PaddleOCR 결과와 다르면 다수결 대신 원본으로 판정한다. 번역은 별도 파일에 쓴다.
## 실패·완료
메모리 부족이면 페이지 단위로 줄이고 모델이 허용되지 않으면 제공된 도구로 전환한다. 중요 필드/구조 확인과 미확정 표시가 끝나면 완료. 이 프로젝트에는 Skill이 설치되며 모델 가중치는 포함하지 않는다. 실제 추론은 미검증이다.
