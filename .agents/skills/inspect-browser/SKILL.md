# 브라우저 확인

## 입력과 출력
입력: URL, 사용자 경로, 기대 동작, 허용 계정/작업 범위.
출력: 접속 조건, 재현 단계, 기대/실제 동작, URL·시각·화면·텍스트 근거, 실패/미검증 사유.

## 절차
1. 설치 Playwright/브라우저 또는 연결된 브라우저 도구를 확인한다. 로그인 상태·쿠키 동의 여부·지역/네트워크·뷰포트·시간대를 기록한다. 쿠키 값과 인증 토큰은 기록/커밋하지 않는다.
2. 새 페이지 상태를 읽고 관찰한 role/label/selector로 탐색한다. 화면이 바뀌면 다시 읽는다. 예측한 좌표나 이전 DOM 참조를 반복 사용하지 않는다.
3. 로그인은 사용자가 허용한 계정/세션을 사용한다. 접근 불가를 제품 버그로 확정하지 않는다. 사용자 권한을 넘는 구매·제출·게시 등은 별도 권한을 확인한다.
4. 동적 로딩은 관련 요소/응답을 제한 시간 동안 기다린다. [재현 기록](references/browser.md)에 조건과 관측을 적는다. 고정 sleep만으로 완료를 추정하지 않는다.
5. 반복 캡처에는 `python scripts/capture.py URL OUTPUT --wait-selector SELECTOR`를 사용할 수 있다. 이것은 새 익명 Chromium 세션의 단일 페이지 캡처이며 로그인/임의 조작을 자동 수행하지 않는다.
6. 버그는 최소 재현 단계, 기대 동작, 실제 동작을 구분하고 재실행한다. 에러/스크린샷과 영향을 받은 R-ID를 verify-results로 전달한다.

## 실패 전환 및 완료
브라우저 미설치면 연결된 도구로 전환하거나 설치 방법을 보고한다. 401/403·쿠키·시간 초과는 조건별로 한정 재시도하고 원인을 기록한다. 텍스트 HTTP 응답은 대체 조사일 뿐 화면 동작 검증으로 간주하지 않는다. 재현 근거와 접속 조건, 미검증 범위가 기록되면 완료다.
