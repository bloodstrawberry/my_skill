# OCR 추출

## 입력과 출력
입력: 원본 이미지 또는 페이지별 렌더링, 언어, 중요 필드, 품질 기준.
출력: 원문 텍스트/TSV 또는 JSON, page·bbox·도구·설정, 불확실 필드, 별도 번역/해석.

## 절차
1. 설치된 OCR/이미지 도구와 언어 데이터를 확인한다. PDF 텍스트 레이어를 먼저 검사하고 텍스트가 없는 페이지는 렌더링한다. [도구·영역 처리](references/tools.md)를 읽는다.
2. Tesseract가 있으면 `python scripts/ocr.py IMAGE OUTPUT.json --lang kor+eng`로 실행한다. 스크립트는 단일 이미지용이며 PDF 변환이나 표 구조 복원은 하지 않는다.
3. 작은 글자·복잡한 배치는 원본 좌표를 보존하여 영역 분할한다. 인접 타일에 겹침을 두고 bbox를 원본 좌표로 환산한다. 겹친 결과는 위치·문자 일치로 중복 후보를 표시하고 표 경계 누락을 원본 대조한다.
4. 숫자·고유명사·날짜·코드와 낮은 신뢰도 토큰은 사람이 원본 대조한다. 도구 점수는 정답 확률이 아니다. 판독 불가를 임의 보완하지 않는다.
5. 표는 행·열·병합 관계, 단위, 빈 셀/판독 불가를 구분한다. 원문 추출을 고정한 뒤 번역/추론을 별도 파일에 기록한다.
6. 표본에서 누락이나 중요 필드 오류가 있으면 회전/해상도/PSM을 바꾸고, 개선이 없으면 설치된 대체 OCR/사용 가능한 비전 도구로 전환한다. 원본·대안 결과 모두 보존한다.

## 실패 전환 및 완료
도구/언어 데이터가 없으면 가능한 다른 로컬 도구나 수동 대조로 전환한다. 원격 업로드는 자료 정책과 허용 여부를 먼저 확인한다. 중요 필드가 확인되거나 미확정으로 표시되고 모든 페이지/영역이 추적될 때 추출 완료. OCR 품질 검증 완료 여부는 별도로 보고한다.
