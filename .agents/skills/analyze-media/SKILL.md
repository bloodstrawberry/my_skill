# 음성·영상 분석

## 입력과 출력
입력: 원본 미디어, 찾을 사건/발화, 언어, 처리 예산.
출력: 원본 해시, chunk 계획, 원본 기준 start/end 전사, 장면 이미지와 시간 매핑, 불명확/누락 구간 목록.

## 절차
1. ffprobe 또는 사용 가능한 미디어 도구로 길이, 스트림, 시작 시각, 프레임레이트를 확인한다. 없는 트랙은 만들어내지 않는다.
2. 짧은 파일은 직접 처리하고 긴 파일은 `python scripts/segments.py DURATION --chunk 300 --overlap 5 --output PLAN.json`으로 겹침 계획을 만든다. 이는 분할 계획만 생성하며 미디어를 실제 변환하지 않는다.
3. [추출과 전사 절차](references/tools.md)에 따라 설치된 FFmpeg와 로컬 ASR 또는 허용된 전사 도구를 사용한다. 특정 모델/서비스를 필수로 정하지 않는다.
4. chunk-local 시각에 chunk 시작값을 더해 원본 초로 환산한다. 반복 발화는 텍스트만으로 지우지 말고 시간·파형/영상 문맥으로 겹침을 대조한다.
5. 관련 장면은 원본 timestamp와 선택 이유를 기록한다. 고정 간격 샘플은 짧은 사건을 놓칠 수 있으므로 필요한 시간대를 촘촘히 재검토한다.
6. [inaudible], 화자 불명, 겹친 발화, 잘린 문장, 추정 발화를 구분한다. 음성 특징만으로 실명 화자를 확정하지 않는다. 원문과 번역/요약을 분리한다.
7. 모든 구간 처리 여부와 chunk 경계의 중복·누락을 점검한다. 숫자·이름·시간은 원음을 다시 듣고 verify-results로 넘긴다.

## 실패 전환 및 완료
잡음/언어/메모리 문제면 짧은 구간, 채널 분리, 다른 설치 ASR/사용 가능 도구로 전환한다. 원본은 보존한다. 전사 도구가 없으면 장면/구간 계획까지 수행하고 전사를 미검증으로 보고한다. 전 구간이 결과 또는 명시된 미처리 상태를 가지며 시간 매핑과 불확실성이 남으면 단계 완료다.
